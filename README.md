# Букет с характером — Skillbox

Цветочная лавка ко Дню учителя. HTML/CSS/JS без сборки и внешних зависимостей.

Сайт: https://skillboxcommunity.github.io/skillbox-bouquet/

Запуск: `python3 -m http.server 8766 --bind 127.0.0.1 --directory bouquet` из родительской папки. Открыть http://127.0.0.1:8766.

- Четыре основы, включая полностью бесцветочный кофейный набор.
- 90 видов предметов в 6 категориях, до 15 предметов в букете, повторы разрешены.
- Быстрый переход к выбранным предметам.
- Удаление, закрепление от случайной замены, «Удивите меня», смена композиции и возврат.
- 5 цветочных палитр, 4 упаковки, 3 ленты, 3 композиции.
- Свой текст до 350 символов, готовые пожелания, PNG 1080 × 1350.
- Десктоп: постоянная сцена слева, прокручиваемый редактор справа.
- Телефон: постоянная сцена сверху, прокручиваемая панель внизу.

Без аналитики, загрузки изображений и хранения текста. После обновления страницы изменения сбрасываются. Для сохранения результата скачайте открытку. Если автоматическая загрузка не срабатывает, диалог результата содержит «Сохранить PNG» и «Открыть картинку».

Предыдущая версия сохранена в previous-version.
